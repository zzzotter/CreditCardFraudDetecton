3. PR 曲线可视化与分析
下图展示了逻辑回归模型在验证集上的精确率-召回率（Precision-Recall）曲线：

https://github.com/zzzotter/CreditCardFraudDetecton/blob/main/results/figures/logistic_regression_pr_curve.png

PR 曲线解读：

曲线走势：当 Recall（召回率）从 0 提升至 0.8 左右时，Precision（精确率）能够保持在 0.6 ~ 0.8 左右的较高水平。这说明模型具备良好的基础排序能力，能够将大部分欺诈交易排在前面。

断崖式下跌：当 Recall 超过 0.8 后，Precision 出现了断崖式下跌，直接逼近 0。这表明为了抓出最后那一小部分（约 20%）极度隐蔽的欺诈交易，模型不得不把几乎所有交易都判定为欺诈，从而导致精确率彻底崩溃。

4. 模型综合评价
结合指标表与 PR 曲线，对当前逻辑回归基线做如下评价：

ROC-AUC 高达 0.9684，但在极端不平衡下这是失真的。真正有参考价值的是 PR-AUC = 0.6275。这个成绩作为基线是合格的，但仍有极大提升空间。

高召回与高误报的矛盾：Recall 达到 87.84%（74笔欺诈抓出了65个），但代价是 Precision 仅为 6.70%。在 0.5 的阈值下，产生了高达 905 笔误报。

后续优化方向：

1.引入非线性模型（如随机森林、XGBoost），寻找更复杂的特征组合。
2.在验证集上重新寻找最佳分类阈值（例如提高至 0.8），牺牲少量召回率来换取精确率的巨大提升，将误报控制在合理范围内。
