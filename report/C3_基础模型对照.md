# 基础模型对照（C·DAY3）：随机森林 vs LightGBM，无处理 vs 类别权重

更新：2026-11-27。

## 一、目标与范围

在**相同数据划分**上比较随机森林（RF）与 LightGBM 两个基线的效果，并对每个模型分别纳入**无处理**（不加类别权重）与**类别权重**（`class_weight="balanced"`）两种方案，共 4 个固定基线。所有模型统一使用 [`src/evaluation.py`](../src/evaluation.py) 的 `evaluate()` 计算指标，阈值统一为 `0.5`，验证集预测概率已保留。

## 二、实验设置

| 项目 | 取值 |
| --- | --- |
| 数据划分 | `data/processed/` 70/15/15 分层抽样，随机种子 42，本轮不重新划分 |
| 训练集 | 199,364 行 × 30 特征，欺诈 344（0.1725%） |
| 验证集 | 42,721 行，欺诈 74（0.1732%） |
| 测试集 | 本轮完全不读取（留待 DAY7 最终评价） |
| 阈值 | 0.5 |
| 正类 | 欺诈 = 1 |
| 指标 | AP、Recall、Precision、F1、MCC、FP、FN（另附 TP/TN/ROC-AUC） |

固定基线超参数（不做调参，避免使用验证集信息）：

| 模型 | 固定超参数 |
| --- | --- |
| Random Forest | `n_estimators=100, random_state=42, n_jobs=-1`；类别权重方案再加 `class_weight="balanced"` |
| LightGBM | `n_estimators=500, learning_rate=0.05, num_leaves=31, min_child_samples=20, subsample=0.9, subsample_freq=1, colsample_bytree=0.9, random_state=42, deterministic=True, force_col_wise=True`；类别权重方案再加 `class_weight="balanced"` |

## 四、结果分析

1. **随机森林（无处理）综合二元指标最好**：F1=0.8485、MCC=0.8546 均为四者最高，且误报最少（FP=2）。代价是召回率略低（0.7568），漏报 18 笔欺诈。

2. **LightGBM（类别权重）排序能力与召回最好**：AP=0.8163（与 RF 无处理基本持平）、Recall=0.7703 为四者最高，FP 仅 4、FN 仅 17。类别权重对 LightGBM 提升显著（AP 0.7159→0.8163，Recall 0.6892→0.7703）。

3. **类别权重对两个模型方向相反**：
   - RF 加 `class_weight="balanced"` 后反而变差（F1 0.8485→0.8029，FP 2→8）。随机森林本身通过自助采样与树集成对不平衡已有一定稳健性，此处强行加权增加了误报。
   - LightGBM 加 `class_weight="balanced"` 后明显变好，说明梯度提升在 0.17% 正例下不加权时分裂被多数类主导。

4. **ROC-AUC 在极端不平衡下失真**：四者 ROC-AUC 均 ≥0.93，但 AP 从 0.716 到 0.818 差异明显。比较整体排序能力应以 **AP** 为准。

5. **阈值 0.5 只是基线**：当前单点指标不能决定最终方案。DAY6 将在验证集上比较不同阈值下的误报/漏报代价，再确定最终配置；测试集仍只用于 DAY7 的一次性评价。
