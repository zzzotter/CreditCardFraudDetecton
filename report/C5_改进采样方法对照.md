# 改进采样方法对照（C·DAY5）：Borderline-SMOTE 与 Conservative SMOTE

更新：2026-11-27。

## 一、目标与范围

对接 **Borderline-SMOTE** 与 **Conservative SMOTE** 两种改进采样，并**优先在表现较好的模型上比较**（随机森林 RF、LightGBM），不做 (模型 × 类别权重 × 采样) 的穷举组合。所有采样只在训练集执行，验证集保留真实类别比例，统一用 [`src/evaluation.py`](../src/evaluation.py) 评价，阈值 0.5。

## 二、实验设置

| 项目 | 取值 |
| --- | --- |
| 数据划分 | `data/processed/` 70/15/15 分层抽样，随机种子 42，不重新划分 |
| 训练集 / 验证集 | 199,364 行（欺诈 344）/ 42,721 行（欺诈 74） |
| 测试集 | 本轮不读取（留待 DAY7） |
| 比较模型 | Random Forest（`n_estimators=100`）、LightGBM（500 树固定基线），**均不加类别权重** |
| 阈值 / 指标 | 0.5；AP、Recall、Precision、F1、MCC、FP、FN |

四种采样方案（对照用，均只在训练集执行）：

| 方案 | 生成规则 | 训练样本量 | 新增欺诈 |
| --- | --- | ---: | ---: |
| 无采样 | 原始训练集 | 199,364 | 0 |
| 普通 SMOTE | 真实欺诈与其 k 近邻插值，`k=5`，`seed=42` | 398,040 | 198,676 |
| Borderline-SMOTE | 以边界欺诈点为起点的 `borderline-1`，`k=5, m=10, seed=42` | 398,040 | 198,676 |
| Conservative SMOTE | 限量生成 + 几何/可信度过滤，最终保留 517 条合成样本 | 199,881 | 517 |

## 四、结果分析

1. **LightGBM + Conservative SMOTE 的整体排序最好（AP=0.8365，八组最高）**，精确率 0.9483、误报仅 3。它只用了 517 条合成样本（约为普通 SMOTE 的 0.26%），却在保持高精度的同时明显拉高了 LightGBM 的排序能力（无采样 AP 仅 0.7159）。

2. **RF + Borderline-SMOTE 的二元综合指标最好（F1=0.8462、MCC=0.8542），误报最少（FP=1）**，精确率 0.9821。相比 RF 无采样，它在几乎不损失综合指标的情况下把误报从 2 降到 1。

3. **改进采样普遍优于普通 SMOTE 的“误报控制”**：普通 SMOTE 虽然召回最高（LightGBM 0.8243、RF 0.7703），但误报最多（11、10）；Borderline-SMOTE 与 Conservative SMOTE 把误报显著压到 1～5，代价是召回略降（0.74～0.76）。

4. **Conservation SMOTE 与 B 模块结果一致**：RF + Conservative SMOTE 的 AP=0.8196、Recall=0.7432、F1=0.8397、MCC=0.8466、FP=2 与 B 采样报告逐位一致（因使用固定保存的 517 条合成样本）。RF + Borderline-SMOTE 的 Recall 为 0.7432（55/74），与 B 初步的 0.7297（54/74）差 1 笔，源于 imbalanced-learn 版本（本轮 0.14.2 vs 历史 0.13.0）下合成样本的细微差异；结论方向不变。

5. **“避免穷举”的取舍**：本轮只在 RF 与 LightGBM 两个较好模型上、以默认（无类别权重）配置比较四种采样，共 8 组，未把类别权重再叠加进采样组合。若需进一步提召回，DAY6 将结合阈值与误报/漏报成本在候选配置间权衡。
