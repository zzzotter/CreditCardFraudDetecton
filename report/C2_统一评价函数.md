# 统一评价函数与指标定义（C·DAY2）

更新：2026-11-27。

## 一、目标与范围

本轮为「模型训练与评价（C）」建立**唯一**的评价口径，供 DAY3—DAY7 的模型对照、阈值选择与最终测试集评价复用，保证所有方法在同一套指标定义下横向比较。

交付物：

1. 统一评价代码 [`src/evaluation.py`](../src/evaluation.py)；
2. 本文档：统一指标定义（含公式、取值约定与使用方式）。

## 二、统一约定

| 项目 | 约定 |
| --- | --- |
| 正类 | 欺诈 = 1，正常 = 0 |
| 连续得分 `y_score` | 一律表示「该样本为欺诈」的得分/概率，越大越可能是欺诈。监督模型取 `predict_proba(X)[:, 1]`；无监督方法取异常得分（越大越异常） |
| 二值预测 `y_pred` | `y_score >= threshold`，阈值缺省 `0.5` |
| 采样范围 | 采样只作用于训练集；验证集与测试集保留真实类别比例，只做预测与评价 |
| 随机种子 | 42 |

## 三、混淆矩阵计数

以「欺诈为正类」，四个计数为：

| 计数 | 含义 |
| --- | --- |
| TP | 被正确判为欺诈的真实欺诈 |
| FP | 被误报为欺诈的正常交易（**误报数**） |
| FN | 被漏掉的真实欺诈（**漏报数**） |
| TN | 被正确判为正常的正常交易 |

## 四、统一指标定义

| 指标 | 公式 / 定义 | 取值 | sklearn 实现 |
| --- | --- | --- | --- |
| **AP** | Average Precision（平均精确率），PR 曲线下面积，等价于 PR-AUC。**不是** Precision/Recall 的比值，也**不**与梯形积分面积混用 | 0～1，越大越好 | `average_precision_score` |
| **Recall** | TP / (TP + FN)，真实欺诈中被检出的比例（召回率/查全率） | 0～1，越大越好 | `recall_score` |
| **Precision** | TP / (TP + FP)，预测为欺诈的样本中真实欺诈的比例（精确率/查准率） | 0～1，越大越好 | `precision_score` |
| **F1** | 2·Precision·Recall / (Precision + Recall)，P 与 R 的调和平均 | 0～1，越大越好 | `f1_score` |
| **MCC** | (TP·TN − FP·FN) / √[(TP+FP)(TP+FN)(TN+FP)(TN+FN)]，综合四类计数的相关系数，对类别不平衡更稳健 | −1～1，越大越好 | `matthews_corrcoef` |
| **FP** | 误报数（正常交易被误判为欺诈的数量） | 非负整数，越小越好 | 由 `confusion_matrix` 得到 |
| **FN** | 漏报数（真实欺诈被漏掉的数量） | 非负整数，越小越好 | 由 `confusion_matrix` 得到 |

辅助输出（便于核对，不影响统一口径）：TP、TN、ROC-AUC、样本数 `n_samples`、欺诈数 `n_fraud`。

- Precision、Recall、F1 在分母为 0 时取 `zero_division=0`。
- MCC、AP、ROC-AUC 在验证/测试集只有单一类别时记为 `NaN`（本项目验证集含 74 条欺诈、42,647 条正常，实际不会触发）。

### 指标解读要点

本数据极端不平衡（欺诈占比约 0.173%），不能只看准确率或召回率：

- **AP** 衡量整体排序能力（阈值无关），是首选的整体评价指标；
- **Precision / FP** 反映误报代价——在信用卡场景误报会带来复核成本；
- **Recall / FN** 反映漏报代价——漏掉欺诈直接造成损失；
- **F1、MCC** 综合精确率与召回率，用于单阈值下的综合比较。

## 五、保留验证集预测概率

评价时**必须保留连续得分** `y_score`，不能只留 0/1 标签，否则后续无法调整阈值或绘制 PR 曲线。统一概率文件列如下：

| 列 | 含义 |
| --- | --- |
| `y_true` | 真实标签（0/1） |
| `y_score` | 该样本为欺诈的概率/得分 |
| `y_pred` | 按当前阈值二值化的预测（0/1） |
| `threshold` | 二值化阈值 |

已有基线预测概率已保留在 [`results/tables/`](../results/tables/)（`logistic_regression_predictions.csv`、`random_forest_predictions.csv`）。后续新模型的验证集概率统一经 `save_validation_predictions()` 输出。

## 六、使用方式

```python
from src.evaluation import evaluate, save_validation_predictions

# 模型在验证集上的欺诈概率
y_score = model.predict_proba(X_valid)[:, 1]

# 统一评价（返回 dict，含 AP/Recall/Precision/F1/MCC/FP/FN/TP/TN/ROC_AUC 等）
metrics = evaluate(y_valid, y_score, threshold=0.5, model="Random Forest")

# 保留验证集预测概率
path = save_validation_predictions(
    y_valid, y_score, threshold=0.5,
    model_name="Random Forest",
    out_dir="results/tables",
)
```
